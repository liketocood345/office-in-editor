# Office in Editor 设计手册

本手册描述当前仓库实现的 VS Code / Cursor 分支。DeepSeek Harness 适配不在本版范围内。这里不记录本机路径、账号或聊天原文。

## 产品形态

产品是两层插件，不是独立软件、托盘、系统服务或开机启动项。

```text
一份 Office 加载项
        │
   共享 Core（私有执行器）
        │
同一份 VSIX：VS Code 与 Cursor
```

- Office 加载项负责 Ribbon、右键 Add to Chat、选区捕获，以及受白名单约束的原生对象模型读写。
- Core 负责身份、引用、聊天路由、MCP、配额、去重和可恢复写事务。
- VSIX 只做宿主薄适配：视图、命令、MCP 注册和诚实的控制标签页。它不假装自己是 Office 编辑器。

直接打开 Office 与从编辑器打开，使用同一份加载项和同一个 Core。

## 两种打开方式

独立模式：Office 正常启动。Ribbon 列出已经由 MCP App 显式登记的聊天。未选择具体聊天时，右键 Add to Chat 可见但禁用。选中后只把引用排队，不自动发送消息，也不改投到别的聊天。

编辑器模式：VS Code 与 Cursor 共用一个 VSIX。控制标签页展示引用、已连接的 Office 实例和已登记聊天。原生 Office 窗口嵌入编辑器标签页目前没有公开宿主契约，因此本版明确不做。打开本地文档会启动用户已安装的 Word、Excel 或 PowerPoint，而不是在编辑器里再画一套 Office。

## 明确未实现

- 把 Office 窗口嵌进 VS Code 或 Cursor 标签页。
- 把 Office 原生 AutoSave 的存储后端改成普通本地文件。本机若没有这项原生能力，不做定时保存、去抖保存、AutoRecover 或“保存后复制”来冒充。
- 猜测“最近一个聊天”并自动投递。
- 任意宏、任意 COM、删除文件、关闭时丢弃修改。

这些限制会在健康检查和编辑器能力面板里保持为否，不因为写操作可用而改口。

## Add to Chat

右键命令请求排在 Cut 之前，这是相对顺序，不保证在所有 Office 版本里绝对第一。捕获的是当前语义选区：Word 文本范围、Excel 工作表区域、PowerPoint 文本、形状或少量幻灯片。空选区、过大选区和不支持的对象会被拒绝，不用整个文档代替。

引用是不可变的，有容量上限。释放引用只删除插件自己的引用记录，不删除用户原件。

## Agent 操作 Office

MCP 写操作走 Office 原生对象模型，并由 Core 串行化到同一文档。

| 操作 | 作用 |
| --- | --- |
| `office_inspect_document` | 读取已绑定文档和该文档实际允许的写种类 |
| `office_apply_edit` | 执行一次白名单编辑 |
| `office_revert_edit` | 仅当编辑后的校验仍匹配时撤销 |
| `office_save_document` | 对已经有本地路径的文档调用一次手动 Save |
| `office_get_operation` | 查看结果，不重放 |
| `office_release_operation` | 用户明确确认后释放恢复材料，保留去重墓碑 |

允许的编辑种类：

- Word：在正文指定字符位置插入有限长度文本。
- Excel：写入不超过 200 个单元格的值，或写入以 `=` 开头的公式。
- PowerPoint：在末尾新增一张空白幻灯片，或在指定幻灯片上新增一个文本框。

调用方必须自带稳定的 `operationId`。相同身份和相同参数不会执行第二次。Core 在真正改文档之前把补偿数据写入恢复记录。若响应丢失，结果记为未知，禁止换一个新编号重做。确认文档没有被改到一半之后，才能显式释放该未知记录。

撤销只覆盖这一次编辑。用户之后又改过同一区域时，撤销会被拒绝。Excel 的 COM 写入可能清掉 Excel 自己的撤销栈，不能把 Ctrl+Z 当成唯一恢复手段。

手动 Save 只接受已经存在的本地 `.docx`、`.xlsx`、`.pptx`。未保存文档不会弹出另存为对话框。Save 不修改 `AutoSaveOn`，也不把文档标成已保存来假装落盘。

## 风险边界

- 不安装全局键盘或鼠标钩子，不用 SendKeys 或剪贴板监听。
- 不在后台抢焦点，不调用会主动激活窗口的 Select。
- 不轮询文档，不因为空闲而反复读写磁盘。
- 相同故障不循环弹窗。失败写在 Ribbon 状态里。
- 恢复材料有数量和体积上限。满额后停止新增编辑，不自动删掉尚未确认的恢复记录。
- 超时视为结果未知，不自动重试写操作，不结束 Office 进程。
- 卸载编辑器扩展不卸载 Office 加载项。卸载加载项不删除用户文档或引用材料。注册变更等到 Office 下一次正常启动生效，安装器不关闭正在运行的 Office。

## 安装

构建产物是共享 Core、一份 Office 加载项 DLL，以及一个同时给 VS Code 和 Cursor 的 VSIX。安装脚本把它们放到当前用户的产品目录，并用当前用户注册表登记加载项。不写机器级注册表，不把 Core 注册成服务。

DSH 包不在本版安装范围内。
